# Mote Desktop Support

Status: **superseded**. The published support page is the one served from the
website repository (`mote-website`), which the application links to at
`https://motedesktop.com/support`. Change the site first, and treat this file as
the record of what the pre-launch draft said.

Mote Desktop is an unofficial Windows desktop controller for compatible Philips
Hue devices. It is not affiliated with or endorsed by Signify.

## Requirements

- Windows 10 or Windows 11 on an x64 PC.
- A compatible Philips Hue Bridge on the same local network for Hue light,
  room, zone, scene, and PC Sync features.
- The Hue Bridge link button must be physically accessible during pairing and
  when provisioning PC Sync credentials.
- PC Sync requires a compatible Hue entertainment area and supported Windows
  display or system-audio capture.
- Sync Box features require a compatible Hue Play HDMI Sync Box already
  connected to Wi-Fi with the official Hue app.

## Before contacting support

1. Confirm the PC and Hue Bridge or Sync Box are powered and on the same local
   network.
2. Confirm Windows Firewall or other security software is not blocking Mote
   Desktop.
3. Restart the app and use the reconnect action if the bridge is unreachable.
4. Check the release notes and known limitations for your installed version.
5. In **Settings → About & Support**, copy the sanitized app information.

## Contacting support

The final support email address and expected response time will be added before
publication. Include:

- The sanitized app information from Settings.
- What you expected to happen and what happened instead.
- Steps that reproduce the problem.
- Whether the issue affects bridge control, PC Sync, Sync Box, or widgets.

Do not send Hue application keys, entertainment credentials, Sync Box tokens,
bridge or Sync Box addresses, screenshots containing private information,
captured PC Sync content, or unrelated personal information.

The privacy policy explains how voluntarily submitted support correspondence is
handled and how to request deletion where applicable.

## Request a feature

Missing something that would make Mote Desktop more useful? Send a feature
request through the support channel. Mote Desktop is actively developed, and
requests help shape what gets considered for future releases. While every idea
cannot be guaranteed or scheduled, each request is welcome.

## Removing local data

Removing a bridge or Sync Box in Settings deletes its saved connection from the
application. A verified procedure for clearing all retained preferences and
credentials after uninstall will be added after installer acceptance testing.
