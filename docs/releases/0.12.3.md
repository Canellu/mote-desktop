# 0.12.3 — Widgets and Windows Text size

Prepared on 14 November 2026.

## Scope

- Fix: with Accessibility → Text size above 100%, a widget's window was too
  small for its content by that factor, so the controls were cut off and a
  collapsed mascot was clipped. WebView2 draws at display scale times text
  size; the backend sized from display scale alone. `text_scale()` reads
  `TextScaleFactor` and every CSS-to-pixel conversion in `widget.rs` now
  includes it. This, not display scale, was what 0.12.1 set out to fix on
  the affected machine.
- Native scroll containers replaced with `ScrollArea` (settings sidebar,
  wizard pages, device scan results, map popover and canvas, debug panel).
  Select and dropdown menus hide their native bar with `no-scrollbar`.

No settings migration. A widget stored collapsed at the old size is
re-measured on its next collapse.
