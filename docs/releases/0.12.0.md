# 0.12.0 — A moth for your desktop

Prepared on 30 October 2026. This is a release candidate; it has not been
submitted to Partner Center or published by this preparation.

## Scope

- Five animated moth styles, with optional animation and facing direction.
- Collapse into a moth, named pill, or bubble; drag to move and click to open.
- Stack or fade in both directions, expansion direction including centered
  opening, auto collapse, and separate open/collapsed sizing with Pro.
- Pinned controls stay visible without a background until the top edge is
  hovered; expansion keeps the background until the pointer leaves.
- No native Windows frame flash, small-widget moth fitting, and confirmation
  before removing a control.
- Light identification completes its breathing effect after 1.5 seconds.

Mascot and fold options work with the free widget. Custom sizes, pinning,
multiple widgets, and multiple controls remain Pro.

## Rollout

1. Smoke-test the production candidate on Windows: each collapsed look,
   each moth style, animation off, facing, stack/fade, centered and corner
   expansion, edge-of-monitor placement, auto collapse, pinning, separate
   sizes, and control-removal confirmation. Check Free and Pro behavior.
2. Upload the unsigned `0.12.0.0` MSIX to the next Partner Center submission.
   Microsoft signs the distributed package. Carry across the updated
   description, feature bullets, What's new, and screenshot captions.
3. Check for live package flights and update or remove obsolete ones so
   testers can receive this release. Submit for certification after validation.
4. Publish the prepared website changes when 0.12.0 is available in the Store,
   so visitors can install the version the page describes.
5. Record the submission ID and certification result, then create the
   immutable `v0.12.0` release tag at the verified release commit.

The personal Pro debug install is separate from the production Store build.
This release preparation does not replace the installed personal app.
