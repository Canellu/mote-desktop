# 0.12.2 — Copy scenes

Prepared on 13 November 2026.

## Scope

- Fix: Copy to… for scenes failed silently (feedback `f_togaac56b5e68555`).
  The copy posted each source action to the target's lights unchanged, and
  the bridge refuses a scene whose action sets a feature its light lacks.
  Actions are now fitted to each target light, and only creatable palette
  fields are posted, with a plain-scene fallback.
- Copying skips scenes the target already has by name.
- The Space screen action dialog shows names in its dropdown and stays open
  while a change is applying.
- Bridge rejection messages carry the bridge's reason in release builds, and
  scene creation records a `scene_create` diagnostic step.
- Fix: Back no longer loops between a page and its child (`7cdb0d6`,
  `8dbc1a6`).

No settings migration.

## Release surfaces

- In-app What's new: `CHANGELOG.md`, entry `0.12.2`.
- Partner Center What's new: `docs/microsoft-store-listing-copy.md` and
  [0.12.2-partner-center.md](0.12.2-partner-center.md).
